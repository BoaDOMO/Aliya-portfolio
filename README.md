# Aliya Koy — Portfolio

Personal portfolio site at [aliyakoy.com](https://aliyakoy.com).

- **Stack**: Vanilla HTML/CSS/JS · Tailwind CSS v4 · Font Awesome 6.5 · Google Fonts
- **APIs**: Vercel serverless functions (Gemini AI chat + design suggestions)
- **Deployment**: [Vercel](https://vercel.com)

## Quick Start

```bash
npm install
npm run build   # Compiles Tailwind CSS
```
